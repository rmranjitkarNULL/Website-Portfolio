Embedded Real-Time Digital Oscilloscope

C/C++ RTOS Embedded TI EK-TM4C1294XL DMA FFT
Overview Design Approach Implementation Results
// 01

Overview

A progressive real-time digital oscilloscope and spectrum analyzer built on the TI EK-TM4C1294XL microcontroller. The system evolved from a bare-metal C/C++ implementation into a full TI-RTOS-based instrument capable of deterministic signal acquisition, multi-scale time and voltage scaling, edge-trigger detection, live CPU-load monitoring, and FFT-based spectral analysis.

The final design integrated DMA-driven sampling, timer synchronization, and hardware interrupts to achieve stable 1–2 Msps acquisition with minimal processor overhead.

// 02

Design Approach

The project started as a bare-metal application implementing core oscilloscope functions — edge-trigger search, voltage scaling, and CPU-load measurement. FIFO buffers decoupled ISRs from main-loop execution for better responsiveness.

The architecture migrated to TI-RTOS, converting the ADC sampling routine into a zero-latency Hardware Interrupt (Hwi). Core functionality was split into prioritized tasks for waveform capture, signal processing, display refresh, and user input. Semaphores, Mailboxes, and Mutexes ensured safe data sharing across tasks.

Later iterations added a 1024-point FFT via KissFFT, Blackman windowing, and DMA-based ping-pong buffering for continuous sampling.

// 03

Implementation

Real-time performance was achieved through DMA buffering, adjustable time bases, and trigger-synchronized sampling at 1–2 Msps. Under TI-RTOS scheduling, the Waveform Task guaranteed deterministic sampling while the Processing Task handled waveform scaling and FFT computation.

Switching from ISR-driven to DMA-based sampling dropped CPU utilization from ~73% to 15% at 1 Msps, and 30% at 2 Msps — leaving substantial headroom for real-time computation.

FFT magnitudes were mapped to a dB-scale spectrum with toggleable time/frequency-domain views, rising/falling edge triggering, and dynamic voltage scaling.

// 04

Results & Performance

The completed platform operated as a dual-mode oscilloscope and spectrum analyzer with real-time audio generation, maintaining deterministic timing throughout. Sampling was stable across all voltage and time scales with no dropped frames or missed triggers.

Sustained 2 Msps throughput at 15–30% CPU utilization under DMA validated the task-based RTOS architecture. The system delivered high-fidelity time- and frequency-domain displays within tight RTOS deadlines.
