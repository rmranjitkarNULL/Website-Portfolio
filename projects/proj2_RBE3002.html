Autonomous Mapping Robot

ROS Python Linux SLAM TurtleBot3 A*
Overview Architecture Pure Pursuit Frontier Exploration Path Planning Results
// 01

Overview

A four-person team developed an autonomous mapping robot implementing Simultaneous Localization and Mapping (SLAM) using ROS and Python. The system integrated a LIDAR sensor for real-time environmental perception, frontier-based exploration to identify unknown regions, and path planning and control algorithms to navigate safely and efficiently.

The robot combined AMCL-based localization, obstacle avoidance, and goal selection in a framework leveraging A* for global path planning, pure pursuit for trajectory following, and a potential fields method for real-time steering corrections.

// 02

System Architecture

The system ran on a TurtleBot3 platform organized as a modular network of ROS nodes communicating through topics and services. Gmapping provided real-time SLAM by fusing LiDAR scans with odometry to build a 2D occupancy grid, while AMCL maintained a probabilistic pose estimate through particle filtering.

A custom FrontierFinder node detected unexplored regions, PathPlanner generated collision-free routes via A* on an inflated C-space, and PathMovement executed trajectories using pure pursuit control. This modular design allowed each subsystem to operate asynchronously yet cohesively.

// 03

Pure Pursuit Controller

Instead of stepping between discrete waypoints, the robot continuously calculated a lookahead point along its global path and adjusted steering based on the angular error between heading and that target. This reduced oscillations and maintained curvature continuity.

Rotation-in-place logic handled sharp turns by pausing linear motion and rotating toward the new heading, providing stable and predictable tracking even in narrow or obstacle-dense environments.

// 04

Frontier-Based Exploration

The occupancy grid from SLAM was continuously analyzed to detect frontiers — boundary cells between known free space and unexplored regions. These frontier points were clustered and their centroids computed as potential exploration targets.

Each centroid was scored using a multi-criteria function balancing frontier size and distance from the robot, ensuring efficient exploration. The highest-ranking centroid became the next navigation goal, balancing map coverage and travel cost.

// 05

Path Planning & Localization

A custom A* planner operated on an inflated configuration space incorporating the robot's footprint. The heuristic combined Euclidean distance, distance-to-wall penalties, and angular deviation costs to produce smooth, collision-free paths.

AMCL localization used particle filtering to continuously estimate the robot's pose. Dynamically adjusting particle count based on uncertainty improved efficiency, and no-motion updates while stationary refined pose estimates without requiring movement.

// 06

Results & Performance

Deployed on a TurtleBot3 in a structured indoor environment, the robot successfully mapped all reachable areas in approximately 101 seconds with minimal human input.

The pure pursuit controller produced smooth, stable tracking, and AMCL maintained accuracy within one robot radius during return runs. The combination of frontier exploration, A* planning, and pure pursuit control validated a reliable pipeline for autonomous SLAM-based exploration.
