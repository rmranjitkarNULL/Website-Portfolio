FishShocker9000

C/C++ PCB Design Python Embedded KiCad Teensy 4.1
Overview Circuit Design PCB Firmware Testing
// 01

Overview

A custom embedded bioengineering system developed for UMass Chan Thyme Labs to assist biological research on zebrafish behavior. Designed to deliver precisely timed high-voltage stimulation pulses, the system gives researchers fine-grained control over experimental parameters while maintaining user and animal safety.

The project integrates custom PCB hardware, embedded C/C++ firmware, and Python-based automation scripts into a modular platform for repeatable, high-throughput testing. Future iterations will incorporate computer vision for real-time fish detection and automated stimulus triggering.

// 02

Electrical Circuit Design

The circuit is built around a Teensy 4.1 microcontroller, chosen for its high-speed clock and precise timing. The Teensy generates programmable digital control signals, converted to analog outputs via a DAC and amplified through a precision op-amp stage.

To safely deliver biphasic stimulation in aqueous environments, the signal passes through H-bridges that dynamically reverse polarity between pulses — eliminating DC offset and minimizing electrolysis. A buck converter regulates input power, and output current routes through stainless-steel electrode plates in the zebrafish testing chamber.

// 03

PCB Design & Integration

A two-layer PCB designed in KiCad consolidates all power, logic, and signal-conditioning circuitry. The layout includes pogo-pin connectors for low-resistance contacts with the electrode array and mounting holes for stable enclosure placement.

The routing strategy isolates high-voltage and logic domains, ensuring noise immunity and operator safety. Embedding the microcontroller, H-bridge drivers, and power management on one board achieves a compact, maintainable, and reproducible platform for lab deployment.

// 04

Embedded Firmware

Firmware implemented in C/C++ using PlatformIO ensures deterministic, low-latency control over pulse generation and timing. The modular directory structure (include/, src/, lib/) supports scalability for future features.

The firmware governs DAC output sequences, pulse width modulation, and safety interlocks for high-voltage operation, while providing routines for amplitude and duration calibration. Future revisions will add serial communication with a vision module for closed-loop stimulation.

// 05

Software Testing & Validation

System validation combined Python-based automation scripts with oscilloscope measurements to evaluate pulse amplitude, timing stability, and repetition accuracy under varying conditions. Automated parameter sweeps ensured repeatable tests and rapid calibration.

The testing framework verified microsecond-level timing precision and reliable high-voltage switching. These scripts will serve as the foundation for the future computer vision module, transforming FishShocker9000 into an intelligent, closed-loop biological instrumentation system.
