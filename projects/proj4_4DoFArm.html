4-DoF Vision-Guided Pick-and-Place

MATLAB Robotics Computer Vision Dynamixel Inverse Kinematics
Overview Architecture Kinematics Vision Results
// 01

Overview

A fully integrated vision-guided robotic pick-and-place system built in MATLAB and implemented on a 4-DoF Dynamixel manipulator. The system combines forward and inverse kinematics, differential kinematics, and trajectory generation with computer vision–based perception for autonomous object detection, grasping, and sorting.

Using precise intrinsic and extrinsic calibration, the manipulator achieved sub-millimeter localization accuracy and smooth, repeatable motion across the workspace.

// 02

System Architecture

The architecture was divided into two modular subsystems: a vision system for real-time object detection and a robot control system for motion execution. A calibrated USB camera provided object centroids to MATLAB's ImageProcessor class, which mapped pixels to world coordinates using calibration parameters.

Target locations were passed to the Robot class, which executed motion commands through blocking joint-space and task-space control routines. This modular framework enabled independent debugging, rapid iteration, and reliable synchronization between perception and control.

// 03

Kinematic Modeling & Motion Control

Robot motion was governed by analytical and numerical inverse kinematics. Forward kinematics were formulated using the Denavit–Hartenberg (DH) convention. Analytical IK offered efficient closed-form joint solutions, while the Damped Least Squares (DLS) method improved stability near singularities.

Smooth trajectories were produced using cubic and quintic polynomial interpolation, ensuring bounded velocity and acceleration profiles for each pick-and-place cycle.

// 04

Computer Vision & Calibration

The vision subsystem used MATLAB's Computer Vision Toolbox for intrinsic and extrinsic calibration, mapping 2-D image coordinates into 3-D robot coordinates. A color segmentation pipeline in HSV space isolated colored objects on a checkerboard plane, with centroid detection estimating positions in real time.

Calibration maintained a mean reprojection error below one pixel, enabling millimeter-level localization accuracy. The manipulator could autonomously detect, classify, and sort multiple colored targets with high repeatability.

// 05

Results & Performance

Experimental results demonstrated consistent and precise autonomous manipulation. The system achieved an average localization error of 1.03 mm and a grasp success rate of 94% across 30 trials. End-effector trajectories closely matched planned cubic and quintic profiles.

Each complete pick-and-place cycle averaged ~7 seconds, including detection, trajectory computation, and grasping. These results validated the emphasis on modular system design, calibration accuracy, and smooth trajectory generation.
