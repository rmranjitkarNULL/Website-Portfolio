Autonomous Trash-Collecting Romi

C/C++ Embedded FSM Sensor Fusion MQTT Pololu Romi
Overview Sensing Control MQTT Results
// 01

Overview

An autonomous Romi mobile robot capable of navigating a grid field, detecting AprilTags, collecting trash, and dumping it up a ramp. The system combined sensor fusion, finite state machines, timed control loops, and MQTT communication between multiple microcontrollers to achieve fully autonomous behavior.

This project demonstrated complete integration of perception, control, and inter-device coordination within a constrained embedded environment.

// 02

Sensor Fusion & Perception

The Romi integrated a diverse sensor suite: motor encoders for wheel odometry, a reflectance array for line detection and intersection processing, a load cell with an AD620 instrumentation amplifier for weight measurement (±1 g), and an OpenMV camera via I²C for AprilTag detection.

An onboard IMU measured acceleration and angular velocity, combined through a complementary filter for stable pitch and heading estimates. This continuous multi-sensor blending allowed the robot to interpret terrain changes and react in real time.

// 03

State Machines & Timed Control

The robot's behavior was structured around a modular finite state machine (FSM) governing navigation, perception, and task execution. Each state — LINE_FOLLOW, TURN, PICKUP, DUMP — was time-synchronized using microcontroller timers to maintain consistent update rates.

Timed intervals ensured deterministic control for smooth PID-based line following and synchronized arm movement. This architecture simplified debugging and scalability for additional mission steps while preventing conflicts between parallel sensor and motion threads.

// 04

MQTT Communication

A key system feature was MQTT communication for message exchange between multiple ESP32 boards. A central broker node dispatched task updates and position data, while each Romi acted as a client subscribing to relevant topics.

This lightweight publish-subscribe framework enabled distributed control, allowing robots to share progress states such as "trash collected" or "returning to start." MQTT maintained asynchronous coordination without blocking core control loops.

// 05

Results & Lessons Learned

During the final showcase, the Romi successfully executed the full autonomous pipeline — navigating to correct coordinates, recognizing AprilTags, collecting trash, climbing the ramp, and returning to starting cell. Performance was highly repeatable after PID and threshold refinements.

The project solidified understanding of embedded real-time design, multi-sensor calibration, and the coordination required for scalable robotic autonomy.
