FPGA Light Sensor Interface

Verilog FPGA SPI Basys3 Vivado FSM
Overview Architecture Modules Testbench Results
// 01

Overview

An FPGA-based light-sensing system on the Digilent Basys3 board using Verilog HDL. The design interfaces the PMOD ALS module (ADC081S021 SPI ADC) using a custom-built SPI master and finite state machine.

A 10 MHz clock generated by an MMCM drives all sequential logic, while sampled data is displayed in real time on a four-digit seven-segment display. A behavioral BFM and Verilog testbench verified correct SPI behavior before hardware deployment.

// 02

System Architecture

The top-level design integrates three key modules: a Clock Generator using the Basys3 MMCM to derive a 10 MHz clock (with a two-stage flip-flop to prevent metastability), a Sensor Interface implementing a 2.5 MHz SPI master and four-state FSM, and a Seven-Segment Display Controller multiplexing four displays.

The SPI interface reads 16-bit sensor frames, extracts bits [11:4] as light intensity data, and passes the value to the display controller. The design achieved 57 LUTs and 108 registers with all timing constraints met (WNS = 95 ns, TNS = 0).

// 03

Module Development

The sensor_interface module communicates with the PMOD ALS using SPI. A 24-bit counter sets the 1 Hz sampling period, while a 15-bit shift register captures data on each falling edge of SCLK.

The FSM sequences: IDLE → WAIT → READ → DONE, ensuring chip-select timing and SPI alignment with a simulated 40 ns access delay (TACC). Each module — clock, interface, and display — was individually verified in Vivado simulations before integration.

// 04

Testbench & Verification

A dedicated Behavioral Functional Model (BFM) emulated the PMOD ALS sensor's behavior including its 15-bit data frame format and 40 ns data-access delay. The testbench automatically generated all SPI timing signals and swept four distinct light-intensity cases.

After all 16 bits were captured, bits [11:4] were extracted and compared against expected values. All four test iterations passed, confirming correct SPI alignment, serial shifting, and timing behavior.

// 05

Results & Reflection

The final FPGA implementation successfully integrated clocking, SPI interface, and display modules into a cohesive real-time system. The seven-segment display updated at 1 Hz without flicker, and SPI communication remained stable across all hardware trials.

This project deepened understanding of synchronous digital design, SPI protocols, MMCM clocking, and simulation-driven verification — mirroring industry-grade validation methods for FPGA-based sensor systems.
